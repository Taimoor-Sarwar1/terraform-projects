In this module, following AWS resources are being created:
1. 1 VPC
2. 1 public subnet
3. Internet Gateway
4. Route Table
5. Route Table Association
6. Security Group
7. 1 EC2 instance as Master Node
8. 2 EC2 instances as Worker Nodes

NOTE: After the creation of instances, ssh into them and run the commands from "user-data" file in Master Node and Worker Node respectively, to setup kubernetes on them.
